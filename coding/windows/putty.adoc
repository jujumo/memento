== Terminal type

Note to myself : 
Choosing `xterm-256color` is gonna lead to some trouble at some point (e.g. bad key biding).
Try to keep "putty-256color" and fix the problem on the other end (client side).

Look for terminfo :

[source,bash]
====
cd /tmp
curl -fLO https://ftp.debian.org/debian/pool/main/n/ncurses/ncurses-term_6.6+20260608-2_all.deb
mkdir -p ncurses-term
cd ncurses-term
ar x ../ncurses-term_6.6+20260608-2_all.deb
tar -xf data.tar.xz ./usr/share/terminfo/p/putty-256color
mkdir -p ~/.terminfo/p
cp usr/share/terminfo/p/putty-256color ~/.terminfo/p/
ls -l ~/.terminfo/p/putty-256color
====
